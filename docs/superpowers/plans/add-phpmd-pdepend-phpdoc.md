## Overview

Install three static-analysis / documentation tools into the monorepo dev toolchain and wire them fully into the existing quality pipeline:

| Tool | Package | Purpose |
|------|---------|---------|
| PHP Mess Detector | `phpmd/phpmd ^2.15` | Detects code smells: complexity, dead code, naming |
| PHP Depend | `pdepend/pdepend ^2.16` | Structural coupling/complexity metrics (also a transitive dep of phpmd) |
| phpDocumentor | `phpdocumentor/shim ^3.0` | Generates HTML API docs from source + DocBlocks |

**Key decisions:**
- phpDocumentor is installed via the official `phpdocumentor/shim` package, which downloads the PHAR into `vendor/bin/phpdoc` without pulling all of phpDocumentor's dependency tree. This avoids Symfony 6.x / `league/flysystem ^1.0` conflicts with the project's existing deps.
- PHPMD uses a **baseline-first** approach: `phpmd.baseline.xml` suppresses all existing violations so the gate starts green and only blocks on regressions.
- PHP-Depend is added directly to `require-dev` so `vendor/bin/pdepend` is available even though it also comes as a transitive dep of phpmd.

## Files to Create

### 1. `phpmd.xml` — PHPMD ruleset (repo root)

```xml
<?xml version="1.0"?>
<ruleset
    name="Arazzo PHPMD Rules"
    xmlns="https://phpmd.org/xml/ruleset/1.0.0"
    xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
    xsi:schemaLocation="https://phpmd.org/xml/ruleset/1.0.0 https://phpmd.org/xml/ruleset_xml_schema_1.0.0.xsd"
    xsi:noNamespaceSchemaLocation="https://phpmd.org/xml/ruleset_xml_schema_1.0.0.xsd">
    <description>PHPMD rules for the Arazzo PHP monorepo.</description>

    <!-- Code size: cyclomatic complexity, too many methods/parameters, long methods -->
    <rule ref="rulesets/codesize.xml" />

    <!-- Design: eval/goto usage, number of children, depth of inheritance -->
    <rule ref="rulesets/design.xml" />

    <!-- Unused code: unused local vars, unused parameters, unused private methods -->
    <rule ref="rulesets/unusedcode.xml" />

    <!-- Naming: overly long/short names, boolean method names, constructor naming -->
    <rule ref="rulesets/naming.xml">
        <!-- Short variable names are common and idiomatic in loops and math contexts -->
        <exclude name="ShortVariable" />
    </rule>
</ruleset>
```

**Rationale for excluded rulesets:**
- `cleancode` — opinionated (bans `else`, static methods); creates too much noise for established code
- `controversial` — very opinionated (camelCase, superglobals); not appropriate for a library monorepo

### 7. `scripts/quality-gates.php`

**Change 1:** Add `parsePhpMd()` function after the `parsePint()` function:

```php
/** @return array{status: string, metrics: array<string, int|float|string>, notes: string} */
function parsePhpMd(int $code, string $text): array
{
    // PHPMD text format reports each violation as "  path/to/File.php:42  RuleDescription"
    // Count lines that look like violation entries
    preg_match_all('/^\s+\S+\.php:\d+/m', $text, $matches);
    $violations = count($matches[0]);

    // Fallback: try to parse a summary count if PHPMD prints one
    preg_match('/(\d+)\s+violation/i', $text, $summaryMatch);
    if (isset($summaryMatch[1])) {
        $violations = (int) $summaryMatch[1];
    }

    return [
        'status' => $code === 0 ? 'pass' : 'fail',
        'metrics' => ['violations' => $violations],
        'notes' => $violations > 0 ? "New violations detected: {$violations}" : '',
    ];
}
```

## Execution Order

Run these commands after all file edits are applied:

```bash
# 1. Install new packages
composer update --no-progress --prefer-dist --no-interaction

# 2. Verify tools are available
vendor/bin/phpmd --version
vendor/bin/pdepend --version
vendor/bin/phpdoc --version

# 3. Generate the PHPMD baseline (suppresses all existing violations)
vendor/bin/phpmd \
  packages/core/src,packages/contracts/src,packages/document/src,packages/expression/src,packages/runner/src,packages/cli/src,packages/laravel/src \
  xml phpmd.xml \
  --generate-baseline \
  --baseline-file phpmd.baseline.xml \
  --ignore-violations-on-exit

# 4. Verify PHPMD now exits 0 with baseline applied
vendor/bin/phpmd \
  packages/core/src,packages/contracts/src,packages/document/src,packages/expression/src,packages/runner/src,packages/cli/src,packages/laravel/src \
  ansi phpmd.xml \
  --baseline-file phpmd.baseline.xml \
  --ignore-violations-on-exit
echo "PHPMD exit code: $?"

# 5. Smoke-test phpDocumentor
vendor/bin/phpdoc run

# 6. Run PHP-Depend (outputs to storage/pdepend/)
make pdepend

# 7. Run quality gates to confirm PHPMD gate is green
make quality-gates
```
